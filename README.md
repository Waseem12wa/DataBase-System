# ShopVerse – Online Marketplace Database System  

**ShopVerse** is a comprehensive and dynamic online marketplace database system developed as part of the **Database Systems** course. This project leverages **React** for the frontend, **SQL** for backend database management, and **Node.js** for server-side processing, delivering a seamless full-stack development experience. The system supports key marketplace functionalities like product listings, user management, and order processing, with smooth database integration.  

## Features  

### Product Listings  
- Add, update, and delete products with attributes like name, category, price, and stock availability.  
- Implement a user-friendly interface for browsing and searching products.  
- Display detailed product information with dynamic rendering using React.  

### User Management  
- Secure user registration and authentication system.  
- Manage user profiles and roles (e.g., buyers, sellers, admins).  
- Ensure data integrity and privacy through secure database connections.  

### Order Processing  
- Streamlined cart management and order placement workflows.  
- Track order status (e.g., pending, processed, delivered) in real-time.  
- Maintain transaction history for users and sellers.  

### Database Integration  
- Built with **SQL** for efficient and structured data management.  
- Implements relational database schema to handle complex relationships.  
- Optimized queries for seamless performance and scalability.  

## Technologies Used  
- **Frontend**: React (JSX, CSS)  
- **Backend**: Node.js, Express.js  
- **Database**: SQL (MySQL, PostgreSQL, or similar)  
- **Version Control**: Git and GitHub  

## Key Learning Outcomes  
- Gained hands-on experience in full-stack development.  
- Enhanced skills in React-based UI design and Node.js server-side development.  
- Strengthened understanding of relational database systems and SQL queries.  
- Mastered end-to-end integration of front-end, backend, and database layers.  

## Setup and Installation  

1. Clone the repository:  
   ```bash  
   git clone https://github.com/yourusername/shopverse.git  
   ```  

2. Navigate to the project directory:  
   ```bash  
   cd shopverse  
   ```  

3. Install dependencies for both frontend and backend:  
   ```bash  
   npm install  
   ```  

4. Configure database connection in the backend (e.g., `config/db.js`).  

5. Start the development server:  
   ```bash  
   npm start  
   ```  

6. Access the application in your browser at: `http://localhost:3000`.
